# Fernleaf New Zealand Limited Website

A responsive corporate website based on the supplied visual concept.

## Files
- `index.html` — page content and sections
- `styles.css` — layout, typography, responsive styling
- `script.js` — mobile navigation

## Run locally
Open `index.html` directly in a browser, or use VS Code / Codex with a local server.

Example:
```bash
python3 -m http.server 8000
```

Then visit:
http://localhost:8000

## Before publishing
Replace:
- email address
- phone number
- partner details if required
- image URLs with your licensed/owned images
- legal/compliance wording for wine, food, security and import/export activities
